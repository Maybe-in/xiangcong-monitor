## 技术经验
- 非交互 shell 下 `git rebase --continue` 会报 "Terminal is dumb, EDITOR unset"，需 `git -c core.editor=true rebase --continue`。
- 中文文件名在 `git status --short` 中以八进制转义（如 `\351\246\231...`）输出，直接 grep 中文匹配会失败，应改用 `git ls-files` 或信任 status 输出。
- 远端 CI 抢先推送导致分叉已成常态，`git pull -X ours` 无效，直接走 `git fetch && git rebase origin/main` + `git checkout --theirs <conflicted>` 更稳。
