一、本期速览

本期头号结论：全省综合两源分歧收敛，泸西报价黏性成为主要风险。上期云南全省综合交易价出现源A 3.30 / 源B 3.45 的 0.15 元分歧，本期两个独立转载源完全一致报 3.1-3.5（中值 3.30），省级口径确认落在 3.30；而泸西官方均价标签连续十日锁定 3.45、区间中值连续两期仅 3.35，形成「省级 3.30 < 区间中值 3.35 < 泸西标签 3.45」的三级阶梯，标签补跌压力累积（10-30 与 11-01 已两次出现「全省综合领先、泸西向下收敛」的修复模式）。
行情端：泸西红香葱 3.2-3.5 / 标签 3.45、黑香葱 2.5-2.9 / 2.76 与 11-09 完全持平，通海与全省综合同步横盘；王旗营转载表由 4.00/30吨 降至 3.50/20吨（价 -12.5%、量 -33.3%），价量齐跌，销地未见回暖。同比隔年精确同日 2025-11-10（红 6.25 / 黑 4.16 / 王旗营 6.60）分别 -44.8% / -33.7% / -65.2%，红香葱仍为近五年同期最低且唯一跌破 4 元。
天气端：本轮寒潮影响已近尾声，泸西未来 3 天降水 7.2mm、最高温均 16.5℃（距平 -7.0℃），15 天累计 9.0mm / 3 个雨日，无强降水中心；中央气象台强降雨落点在滇西与滇东北，泸西所在的滇东既不在暴雨带也不在降雪带，短期供给收缩风险有限。
预测：六档中枢（红）3.45 → 3.77 / 3.81 / 3.87 / 3.95 / 4.07 / 3.91 元/公斤，第 6 档较前档小幅回落（4.07 → 3.91），系春节后节日脉冲衰减与 2 月季节因子回落叠加，非趋势反转；情景 C（标签补跌 / 销地续弱）概率维持 40%。
口径铁律：长周期主序列为通货毛葱（元/公斤），预测与「当前中枢」为精品净葱/集散价， 两者相差约 1.66 倍，禁止横向混比；本报告所有价格除特别标注外均为元/公斤， 元/斤报价已 ×2 换算并在明细 note 注明；挂牌价、代办价、推算值均显式标注为非成交口径。
